# AI-Powered Retail Sales Analytics and Sales Prediction

## Project Overview

This project uses data analytics and machine learning to analyze historical Walmart retail sales and predict weekly sales.

The objective is to identify sales patterns, study store and department performance, compare machine learning models, and generate sales predictions that may support retail planning and decision-making.

## Objectives

* Clean and preprocess retail sales data.
* Perform exploratory data analysis (EDA).
* Visualize store-wise, department-wise, and holiday-related sales patterns.
* Engineer features for machine learning.
* Train and compare regression models.
* Evaluate predictions using MAE, RMSE, and R-squared.
* Generate a CSV file containing predicted sales.
* Derive business insights from the analysis.

## Dataset

Source: Walmart Store Sales Forecasting competition on Kaggle.

Dataset URL:
https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting/data

The dataset includes historical sales, store information, and weekly features such as holidays, weather, and economic indicators.

Download the required CSV files from Kaggle and place them in the data directory used by the notebook.

Required files:

* train.csv
* test.csv
* features.csv
* stores.csv

Access may require a Kaggle account and acceptance of the competition rules.

## Machine Learning Models

The project compares:

1. Linear Regression
2. Random Forest Regressor

Model evaluation uses:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R-squared (R²)

The final model is selected based on validation performance.

## How to Run

### Option 1: Google Colab

1. Open the project notebook in Google Colab.
2. Download the dataset from Kaggle.
3. Upload the required CSV files when prompted by the notebook.
4. Run the notebook cells in order.
5. Review the generated charts and model evaluation results.
6. Generate the predicted sales CSV file.

### Option 2: Local Python Environment

1. Install Python.

2. Download the dataset from Kaggle.

3. Place the CSV files in the expected data directory.

4. Install dependencies:

   pip install -r requirements.txt

5. Open the notebook using Jupyter:

   jupyter notebook

6. Open Vinay_RetailSalesAnalytics.ipynb and execute the cells in order.

Note: Local execution instructions and dataset paths must match the final notebook implementation.

## Model Evaluation Results

The project compares Linear Regression and Random Forest Regression using a chronological training and validation split.

| Model             |       MAE |      RMSE |    R² |
| ----------------- | --------: | --------: | ----: |
| Linear Regression | 14477.320 | 20877.373 | 0.095 |
| Random Forest     |  1846.801 |  3819.327 | 0.970 |

Based on the validation results, Random Forest performed better than Linear Regression across all three reported evaluation metrics.

These results describe performance on the validation data. Actual performance on future periods may differ.
